# macro-flightpad

<img width="1606" height="896" alt="image" src="https://github.com/user-attachments/assets/5c2f1302-a973-482d-a4ff-978575e1c1af" />

The Flightpad is a simple 4-key macropad with a rotary encoder mostly intended for playing the occasional flight sim without a HOTAS.

Features:
4 Cherry-MX style keys
1 rotary encoder (I'll be using it for things like roll controls on old emulated console games but you can do whatever you want)
